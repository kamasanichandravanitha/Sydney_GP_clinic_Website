# Sydney GP Clinic Website

A modern, responsive website for Sydney GP Clinic - Book appointments, explore services, and connect with doctors easily.

**Live Demo:** https://sydney-gp-chandravanitha.bolt.host

## Features
- Home, Services, Doctors, About & Contact Pages
- Online Appointment Booking with Booking Modal
- Responsive Design for Mobile & Desktop
- Clean & Modern UI with Tailwind CSS

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide Icons

## How to Run
npm install
npm run dev
